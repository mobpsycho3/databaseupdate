## 🎨 Design Principles Applied

### **Colors:**
```css
/* Backgrounds */
bg-heritage-cream  #FBF8F3
bg-ivory           #FFFFF0

/* Text */
text-deep-brown    #2D1810
text-incense       #4A4A4A

/* Accents */
bg-sandalwood      #8B4513
border-sandalwood  #8B4513

/* Opacity Usage */
border-sandalwood/10  (very subtle)
border-sandalwood/15  (subtle)
border-sandalwood/20  (light)
bg-sandalwood/5       (hover states)
```

### **Typography:**
```jsx
/* Headings - English */
font-family: 'Cormorant Garamond', serif
font-weight: 300-400 (light)

/* Headings - Hindi */
font-family: 'Noto Serif Devanagari', serif

/* Body */
font-family: 'Poppins', sans-serif
font-weight: 300 (light)
```

### **Components:**
```jsx
/* Buttons */
className="bg-sandalwood text-ivory rounded-sm 
          font-light hover:bg-deep-brown border 
          border-sandalwood shadow-sm"

/* Cards */
className="bg-ivory rounded-sm border 
          border-sandalwood/15 shadow-sm"

/* Inputs */
className="border border-sandalwood/20 
          bg-heritage-bg/30 rounded-sm 
          focus:ring-1 focus:ring-sandalwood"
```
